〈手順〉

1.名前と連絡先を入力して次のページに進む。

2.コードを見る順番で指定された最初のコードを閲覧しながら、「内容理解に関する質問」に回答して、次のページに進む。

3.最初に指定されたコードを閲覧しながら、そのコードの評価を行い、次のページに進む。

4.二番目に指定されたコードを選択して次のページに進み、二番目に指定されたコードを閲覧しながら、そのコードの評価を行い、次のページに進む。

5.三番目に指定されたコードを選択して次のページに進み、三番目に指定されたコードを閲覧しながら、そのコードの評価を行い、次のページに進む。

6.指定された順番にすべてのコードについての評価が終わったことを確認し、次のページに進む。

7.「3種類のコードを見た上で答える質問」に回答して、次のページに進み、すべての入力に間違いないなければ回答を送信する。

    例：「N → E → J」と指定された場合(手順の2~5までの例になります)

    2.Nのコードを閲覧しながら、「内容理解に関する質問」に回答する。

    3.Nのコードを閲覧しながら、Nの評価を行う。評価が終わったら次のページに進む。

    4.二番目のコードであるEを選択してページを移動したのち、Eのコードを閲覧しながら、Eの評価を行う。評価が終わったら次のページに進む。

    5.三番目のコードであるJを選択したページを移動したのち、Jのコードを閲覧しながら、Jの評価を行う。評価が終わったら次のページに進む。
